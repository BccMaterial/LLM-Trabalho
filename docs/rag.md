De forma geral, será utilizado a forma de busca vetorial, uma vez que os dados que
virão do RAG são majoritariamente textos ou pdf, como:
- Laudos de exames anteriores
- Documento do encaminhamento do paciente
- Documentos de convênios

O RAG pode ser utilizado para a consulta de informações sobre o paciente, tanto no
agente de priorização, quanto no agente conversacional, na rota de consulta de dados.
